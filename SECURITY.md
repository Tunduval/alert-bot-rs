# Security policy

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/duramson/alert-bot-rs/security/advisories/new)
instead of opening a public issue or pull request.

Include what an attacker can do, the conditions it needs, and a way to
reproduce it. I'll answer as soon as I can and publish a fix and an advisory
once the issue is resolved.

Only the latest commit on `master` is supported; it's what runs in production.
